# Ассистент УшиХвост — ветеринарный помощник

Веб-приложение для ветеринарного врача: сбор анамнеза, протокол осмотра с чек-листом, аудиоплеер для аускультации сердца, OCR-модуль для загрузки исследований и AI-генерация заключения.

## Установка
```bash
npm install
npm run build
```

## Авторизация
- Логин: `admin`
- Пароль: `admin`

## Функции
- 📋 Сбор анамнеза (40+ полей)
- 🩺 Осмотр по системам с нормами для собак и кошек
- 🫀 Аускультация сердца с аудиоплеером
- 📑 Загрузка исследований (OCR через Z.AI Vision)
- 🤖 AI-генерация дифференциальных диагнозов и плана лечения
- 💊 Калькулятор дозировок по весу пациента
- 📄 Экспорт протокола в TXT/PDF/JPEG/Word

## Технологии
- Next.js 16 + React 19
- TypeScript + Tailwind + shadcn/ui
- Z.AI (GLM-4.5-air для текста, GLM-4.5v для OCR)
- Zustand + Prisma
