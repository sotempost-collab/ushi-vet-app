📱 Установка на iPhone

Откройте в Safari по ссылке выше
Нажмите иконку «Поделиться» (⬆️ внизу)
Выберите «На экран „Домой"»
Нажмите «Добавить»

🤖 Установка на Android

Откройте в Chrome по ссылке выше
Нажмите ⋮ в правом верхнем углу
Выберите «Установить приложение»
Подтвердите установку

💻 Установка на компьютер

Откройте в Chrome или Edge
В адресной строке нажмите иконку ⊕ «Установить»
Подтвердите установку
Открыть в браузере
